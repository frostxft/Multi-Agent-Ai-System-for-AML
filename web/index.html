New to ZEN? Five helpful definitions
Transaction node
One transaction in the benchmark graph. It is not a customer account.
Model score
The graph model output used to rank transactions. It is not a calibrated probability.
Explanation
A model-derived indication of which features and relationships influenced the prediction; not causal or legal evidence.
Evidence
Source-linked facts and separately labeled model outputs that support the investigation.
Human review
An investigator decides what to do with the draft. ZEN does not autonomously file a report.
